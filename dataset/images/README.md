# images/

The 499 site images (`{ID}.jpg`) are hosted on Hugging Face, not in this Git repository:
[thelionlies/tanawpamana-dataset](https://huggingface.co/datasets/thelionlies/tanawpamana-dataset).

To download them into this folder, run from the repository root:

```bash
pip install huggingface_hub
python download_images.py
```

Licenses for every image are listed in `../Tanawpamana_license.csv`.
